# Automation Filter

This document defines when a workflow should become a Zentory automation.

## Automate if

A task is a good automation candidate when it meets most of these conditions:

- it repeats daily or weekly;
- it saves more than 2 hours per week;
- it affects revenue, margin, stock, advertising or operational mistakes;
- there is data to verify the decision;
- the result can be measured.

## Do not automate if

Do not automate when:

- the time saving is less than 30 minutes per week;
- the task is one-off;
- an existing service already solves 80% of the job;
- the risk of an error is higher than the benefit;
- the task is automated only because it looks impressive.

## Decision rule

Automation must improve an operational metric. If the metric, input data, owner and rollback path are unclear, keep the workflow in manual or assistant mode.
