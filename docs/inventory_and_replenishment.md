# Модуль «Отгрузки и подсорты»

Модуль анализирует остатки, скорость продаж, склады, регионы, транзит, план поставки и риски out-of-stock. На этапе scaffold используются только mock-данные, реальные API WB/Ozon/Яндекс Маркета не вызываются.

## Telegram-команды

- `/stocks` — общий отчет по остаткам.
- `/stock_risks` — SKU с риском out-of-stock.
- `/replenishment` — рекомендации по отгрузке и подсорту.
- `/sku_stock <sku>` — отчет по конкретному SKU.

## Входные данные

- SKU;
- общий остаток;
- остаток по складам;
- продажи за 7/14/30 дней;
- среднедневные продажи;
- дни покрытия;
- склад;
- регион;
- транзит;
- план поставки;
- минимальный остаток;
- желаемый запас в днях.

## Выходные данные

- список SKU с риском out-of-stock;
- список SKU с избытком;
- список slow movers;
- рекомендация по подсорту;
- рекомендация по отгрузке;
- приоритет;
- дата, когда товар закончится;
- Telegram alert;
- alert в AdsAgent, если SKU в рекламе и остатка мало.

## Правила

| Условие | Результат |
|---|---|
| Остатка меньше чем на 7 дней | `critical` |
| Остатка меньше чем на 14 дней | `warning` |
| Товар продается, но отсутствует на ключевом складе | предложить подсорт |
| Товар лежит больше 45 дней без движения | отметить как slow mover |
| Продажи растут 3 дня подряд | поднять приоритет подсорта |
| Товар в рекламе, но остатка мало | отправить alert в AdsAgent |

## Безопасность

Система только формирует рекомендации. Реальные поставки, подсорты и изменения рекламы не выполняются автоматически. Любое будущее действие должно проходить через approval, audit log, idempotency и safe mode.
