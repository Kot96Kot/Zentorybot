# Модуль анализа акций

Модуль оценивает, можно ли участвовать в акции без разрушения маржи и прибыли. На этапе scaffold используются mock-данные, реальные API маркетплейсов не вызываются.

## Telegram-команды

- `/promo_check` — проверить все mock-SKU на участие в акции.
- `/promo_sku <sku>` — проверить конкретный SKU.
- `/promo_list` — показать SKU, где акция опасна.

## Входные данные

- SKU;
- текущая цена;
- цена по акции;
- скидка;
- комиссия;
- логистика;
- себестоимость;
- реклама;
- налог;
- минимальная маржа;
- текущие продажи;
- остаток;
- прогноз роста продаж;
- длительность акции.

## Формула прибыли SKU

```text
Прибыль SKU = Выручка - Комиссия - Логистика - Эквайринг - Реклама - Себестоимость - Хранение - Штрафы - Возвратная логистика - Налоги
```

## Выход

- можно участвовать или нельзя;
- минимальная цена;
- прогноз маржи;
- прогноз прибыли;
- риск;
- рекомендация;
- список SKU, где акция опасна.

## Правила

| Условие | Решение |
|---|---|
| Маржа ниже минимальной | запретить участие |
| Остатка меньше 14 дней | отправить warning |
| Рост оборота убивает прибыль | high risk |
| Акция помогает распродать slow mover | разрешить при низкой марже только с approval |
| Цена акции ниже себестоимости + обязательных расходов | critical |

## Approval-only режим

Все действия модуля создаются как рекомендации и требуют approval. Система не меняет цены, не включает участие в акции и не отправляет данные в WB/Ozon/Яндекс Маркет автоматически.
