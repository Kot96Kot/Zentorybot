# Модуль управления внутренней рекламой

Модуль анализирует внутреннюю рекламу маркетплейсов и формирует только рекомендации. Реальные изменения ставок, бюджетов или статусов кампаний не выполняются.

## Цель

Помочь менеджеру быстро понять, какие кампании тратят бюджет эффективно, где ДРР выше лимита, где нужен тест главного фото, проверка цены/оффера или запрет усиления рекламы из-за низкого остатка.

## Telegram-команды

- `/ads_today` — отчет по всем mock-кампаниям за день.
- `/ads_sku <sku>` — отчет по рекламным кампаниям SKU.
- `/ads_campaign <id>` — отчет по конкретной кампании.
- `/ads_alerts` — только кампании с critical/warning alerts.

## Метрики

- показы;
- CTR;
- клики/переходы;
- CPC или CPM;
- расходы;
- заказы;
- выручка;
- ДРР;
- конверсия в корзину;
- конверсия в заказ;
- средняя позиция;
- ставка;
- остаток SKU;
- маржа SKU.

## Правила рекомендаций

| Правило | Recommendation |
|---|---|
| ДРР выше лимита и заказов мало | снизить ставку |
| ДРР высокий и заказов нет | предложить паузу |
| CTR низкий | создать задачу на тест главного фото |
| Корзина хорошая, но заказ слабый | проверить цену/оффер |
| Остатка меньше 7 дней | запретить усиление рекламы |
| Кампания прибыльная | аккуратно поднять ставку |
| Расход за день выше лимита | отправить critical alert |

## Режим работы

Все действия создаются как `recommendation_only`. Система не вызывает реальные API WB/Ozon/Яндекс Маркета и не меняет ставки. Любое будущее применение рекомендации должно пройти через Decision Engine, approval, safe mode, audit log и idempotency.
